# 学マス リハーサル自動周回＆スコア集計ツール

学園アイドルマスター（PC 版）のコンテストのリハーサルを自動で周回し，結果画面のスコアを読み取って，キャラごとの平均（Ave）や分布を集計する Windows 用ツールです．

## ダウンロード

**[最新版の exe をダウンロード](../../releases/latest/download/GakumasRehearsalTool.exe)**（[リリース一覧](../../releases)）

- ダウンロードした `GakumasRehearsalTool.exe` を好きなフォルダに置いて起動するだけで使えます（Python は不要）．
- 起動するとブラウザで操作画面が開きます．詳しい使い方は画面の「📖 使い方」タブを見てください．
- 設定・参照画像・周回結果は exe と同じフォルダに保存されます．
- 初回は Windows の警告（SmartScreen）が出ることがあります．「詳細情報」→「実行」で起動できます．

## 主な機能

- リハーサルの自動周回（開始 → スキップ → 結果の撮影 → 終了 を繰り返し）
- 結果画面の数字読み取り（「ステージ合計 ＝ 3 人のスコア ＋ 最高スコア÷5」で検算・自動補正）
- 9 人のスコアのライブ集計（箱ひげ図・平均・中央値・Q1・Q3）
- 読み取り結果のレビュー・手修正
- 集計ダッシュボード（gktools と同じ形式の度数分布・箱ひげ図，CSV 読込）
- CSV 出力（gktools のリハーサル集計にそのまま読み込める形式あり）
- 編成違いのセッションの結合
- ホットキー：Ctrl+Shift+A 開始 / Ctrl+Shift+Q 中断 / Ctrl+Shift+S スクショ

## 注意

- ゲームを自動で操作するツールは，ゲームの利用規約に反する可能性があります．使用は自己責任でお願いします．
- 読み取り結果は検算していますが完全ではありません．

## ソースから動かす（開発者向け）

```powershell
pip install -r requirements.txt
python run_tool.py
```

exe を自分で作る場合は `build_exe.bat` を実行すると `dist\GakumasRehearsalTool.exe` ができます．
v で始まるタグ（例 `v1.0.0`）を push すると，GitHub Actions が exe を作ってリリースに添付します．
