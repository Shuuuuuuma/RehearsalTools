📖 使い方

学マス（PC 版）のコンテストのリハーサルを自動で周回し，結果画面のスコアを読み取って，キャラごとの平均（Ave）や分布を集計するツールです．

はじめる前に初回の設定周回する 読み取りの確認データを見る・保存する編成を変えたとき ホットキー困ったとき注意

1. はじめる前に

  • Windows 10 / 11 と，PC 版の学マス（ウィンドウ名「gakumas」）が必要です．
  • ツールのウィンドウを閉じると，自動周回もホットキーも止まります．
  • 画面の見た目の部品をインターネットから読み込むので，ネットにつながった状態で使ってください．
  • 設定・参照画像・周回結果は，ツール（exe）と同じフォルダに保存されます．
  • 画面上部のバッジで状態が分かります：ゲーム検出 管理者ではない OCR: template 参照画像 0/3

2. 初回の設定（5 分くらい）

「⚙ 設定・キャリブレーション」タブで行います．設定しなくても色や形による判定で動きますが，やっておくと確実です．

  1. ボタンの参照画像を撮る：ゲームに次の画面を出した状態で，それぞれ「📸 撮影」を押します．
    • 開始する … コンテスト →「リハーサル」画面（編成が並んでいる画面）
    • スキップ … 対戦準備画面で，右下の「コンテスト準備中…」が消えて「スキップ」が明るくなった時
    • 終了 … リハーサル結果画面
  2. 判定テスト：それぞれの画面で「🔍 今の画面で判定テスト」を押し，その画面のボタンだけ「見えている」になるか確認します．
  3. クリックテスト：「『開始する』を押す」などで，実際にゲームのボタンが押されるか確認します．押されない場合は「③ 動作設定」のクリック方式を sendinput に変えて保存し，もう一度試してください．
  4. OCR テスト：結果画面で「今の画面で OCR」を押し，9 人のスコアが正しく読めるか確認します．
  5. 位置がずれている場合は「📷 ゲーム画面を取得」→「編集対象」を選び，画像の上をドラッグ（領域）／クリック（位置）して直し，「設定を保存」．領域を直したら参照画像も撮り直してください．

3. 周回する

  1. ゲームを「コンテスト → リハーサル」画面にします．対戦準備画面の「全対戦スキップ」にチェックを入れておくと速くなります．
  2. 「▶ 実行・ライブ集計」タブで周回数を入れ，保存先を選んで「▶ 開始」．
    • 新しいセッション … 新しく記録を始めます（編成を変えた時はこちら）
    • 既存のセッション … 同じ編成で続きを取ります（編成が違うと開始できません → 6.）
  3. 周回中は右側に 9 人の箱ひげ図と平均・中央値などがリアルタイムで更新されます．
  4. 止める時は「■ 中断」か Ctrl+Shift+Q．

1 周の流れ：リハーサル画面 →「開始する」→（空き枠がある編成なら確認ダイアログの「開始する」）→「コンテスト準備中…」が消えるまで待つ →「スキップ」→ 結果画面を撮影 →「終了」． PC が遅くても「準備中」の間は待ち続けます．ゲームはほかのウィンドウの裏にあっても動きます（クリック方式が sendinput の時は，クリックのたびにゲームが前面に出ます）．最小化はしないでください．

4. 読み取りの確認

  • 結果画面の数字は「ステージ合計 ＝ 3 人のスコア ＋ ボーナス（最高スコア ÷ 5）」で必ず検算しています．
  • 合わない時は自動で読み直し（自動補正），それでも合わない回は 要確認 になり，直すまで集計から外れます．
  • 「✎ OCR レビュー」タブで，切り抜き画像を見ながら数字を直して「修正を保存」．正しいのに要確認になっている行は「確認済にする」．
  • キャラを置いていない枠（「ー」表示）は空欄として記録され，集計には入りません．

5. データを見る・保存する

  • 集計ダッシュボード（右上のリンク）の「📊 リハーサル分析」で，箱ひげ図と度数分布を表示できます．キャラ選択ボタン・箱・表の数字のどれかを押すとそのキャラの分布を表示．「表示:」「箱ひげ図:」で並べ方や表示する人数を切り替えられます．
  • データは「ダッシュボードの全データ」「周回セッション（1 回ずつ）」「CSV 読込」から選べます．CSV はカードにドロップしても読み込めます．
  • CSV の保存：「📁 セッション」タブの「CSV: 全項目／9列（gktools用）／統計」，またはダッシュボードの「💾 CSV」． 「9列（gktools用）」は gktools のリハーサル集計 にそのまま読み込めます．
  • 周回結果は sessions\日時\ フォルダにもあります（結果画面のスクショ・CSV・統計）．「フォルダを開く」ですぐ開けます．グラフは「グラフ」ボタンでこの画面に表示します．

6. 編成を変えたとき（セッションの結合）

ステージ3 を外して速く回したい時などは，新しいセッションで周回してから，あとで結合します．

  1. 「📁 セッション」タブの「🔗 結合」で，結合先（元のデータ）と結合元（足すデータ）を選び「対応付けを作る」．
  2. 編成画像を比べて同じキャラ同士が自動で選ばれます．違っていればプルダウンで直します（キャラが別の枠に移っていても対応付けできます）．
  3. 「結合して新しいセッションを作る」．元の 2 つはそのまま残ります．

7. ホットキー（ツールが前面でなくても使えます）

Ctrl+Shift+A前回の周回数で開始（新しいセッション）
Ctrl+Shift+Q中断
Ctrl+Shift+Sゲーム画面を保存（data\hotkey_screenshots）＋クリップボードにコピー

8. 困ったとき

ボタンが押されない
クリック方式を sendinput に変える／ツールを右クリック →「管理者として実行」で起動する．
途中で止まる
ログに理由が出ます．止まった瞬間の画面がセッションフォルダに stopped_時刻.png として保存され，各ボタンの判定結果もログに出るので，参照画像の撮り直しや領域の調整の手がかりにしてください．
「ゲーム未検出」になる
ゲームを起動し，最小化していないか確認．ウィンドウ名が違う場合は動作設定の「ウィンドウ名」を変更．
読み取りが要確認ばかり
「今の画面で OCR」で確認し，OCR 領域（設定画面の青い枠）が数字に重なっているか確認．Windows の拡大率やウィンドウサイズを変えた後は参照画像も撮り直してください．
起動時に Windows の警告が出る
署名のないアプリのため表示されます．「詳細情報」→「実行」で起動できます．

9. 注意

  • ゲームを自動で操作するツールは，ゲームの利用規約に反する可能性があります．使用は自己責任でお願いします．
  • 読み取り結果は検算していますが，完全ではありません．大事な判断の前には，要確認の行やスクショを確認してください．

🔗 結合

別々に取ったセッションを 1 つにまとめます．結合元の各枠を，結合先のどの枠に足すかを選んでください（編成画像が似ている枠を自動で選びます）．元の 2 つのセッションはそのまま残り，結果は新しいセッションとして保存されます．
